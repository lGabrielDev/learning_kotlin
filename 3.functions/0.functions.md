## Methods com retorno e sem retorno
Assim como no Java, aqui temos methods/functions com e sem retorno.


### Methods com retorno

```kotlin
fun somar(n1: Double, n2: Double): Double {
    return n1 + n2;
}

fun mensagemBonita(): String {
    return "Olá mundo!";
}

fun isEmpty(): Boolean{
    return true;
}
```

:book: Sempre informe o tipo do retorno. 

<br>
<br>

### Methods sem retorno *Unit*

Quando uma function não retorna nada, o tipo dela é `Unit` (equivalente ao `void` do Java).

```kotlin
fun printarMensagem(mensagem: String): Unit{
    println(mensagem);
}
```

📖 Por padrão, quando uma function/method nao retorna nada, o Kotlin já sabe que ela é Unit. Logo, voce nao precisa declarar o retorno desse Unit.

```kt
fun printarMensagem(mensagem: String) {
    println(mensagem);
}
```

## Named Arguments - Escolhendo a ordem dos argumentos

Ao chamar uma function / method voce pode decidir a ordem que vai passar os argumentos.

```kt
fun main(args: Array<String>) {
    println(
        dadosPessoasFormatadinhos(
            age = 33,
            lastName = "naruto",
            firstName = "uzumaki"
        )
    )
}

fun dadosPessoasFormatadinhos(
    firstName: String,
    lastName: String,
    age: Int
): String {
    return """
        Nome: $firstName
        Sobrenome: $lastName
        Idade: $age
    """.trimIndent();
}
```


⚠️ Se voce nomear algum argumento, todos os outros também devem ser nomeados.

## Default Arguments - Valor default de cada parametro

Voce pode definir um valor default para cada um dos parametros da function. 

Assim, esse parametro nao eh mais obrigatorio.

```kt
fun main(args: Array<String>) {
    
    val informacoes1 = informacoesPessoais();
    val informacoes2 = informacoesPessoais(age = 2);
    val informacoes3 = informacoesPessoais(name = "Ronaldo");
    val informacoes4 = informacoesPessoais(age = 222, name = "Ronaldo");
    val informacoes5 = informacoesPessoais("Ronaldo", 44);
}

fun informacoesPessoais(name: String = "usuario random", age: Int = 100): String {
    return """
        Nome: $name
        Age: $age
    """.trimIndent();
}
```

📖 Parâmetro com valor default → não precisa ser informado.

## Single-Expression Functions - Função em uma linha

Quando a function tem apenas 1 expressao simples, voce pode escrever ela em apenas 1 linha.


```kt
//ex 1
fun mensagemBoasVindas1(name: String): String {
    return "Olá $name, seja bem vindo!"
}

fun mensagemBoasVindas2(name: String): String = "Olá $name, seja bem vindo!"



// Ex 2: 
fun somar(n1: Int, n2: Int): Int {
    return  n1 + n2;
}

fun somar (n1: Int, n2: Int): Int = n1 + n2;



// Ex 3: 
fun isEven(n: Int): Boolean {
    return n % 2 == 0;
}

fun isEven(n: Int): Boolean = n % 2 == 0;




// Ex 4: 
fun printarMensagem(): Unit{
    println("salve");
}

fun printarMensagem(): Unit = println("salve");
```

### Misturando uma funcao simples com uma expressao if else simples

Isso...

```kotlin
fun isNameLengthToBig(name: String): Unit{
    if(name.length > 10){
        println("nome gigante");
    }
    else{
        println("ok");
    }
}
```

Conseguimos reduzir pra isso:

```kotlin
fun isNameLengthToBig(name: String): Unit = if(name.length > 10) println("nome gigante") else println("ok");
```
