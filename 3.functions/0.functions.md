## Methods com retorno e sem retorno
Assim como no Java, aqui temos methods/functions com e sem retorno.


### Methods com retorno

```kotlin
fun somar(n1: Double, n2: Double): Double {
    return n1 + n2;
}

fun mensagemBonita(): String {
    return "Olá mundo!";
}

fun isEmpty(): Boolean{
    return true;
}
```

<br>
<br>

### Methods sem retorno *Unit*

Quando uma function não retorna nada, o tipo dela é `Unit` (equivalente ao `void` do Java).

```kotlin
fun printarMensagem(mensagem: String): Unit{
    println(mensagem);
}
```

📖 Por padrão, quando uma function/method nao retorna nada, o Kotlin já sabe que ela é Unit. Logo, voce nao precisa declarar o retorno desse Unit.

```kt
fun printarMensagem(mensagem: String) {
    println(mensagem);
}
```

## Named Arguments - Escolhendo a ordem dos argumentos

Ao chamar uma function/methods voce pode decidir a ordem que vai passar os argumentos.

```kt
fun main(args: Array<String>) {

    val informacoes = informacoesPessoais(age = 44, name = "camila");
    println(informacoes);
}

fun informacoesPessoais(name: String, age: Int): String {
    return """
        Nome: $name
        Age: $age
    """.trimIndent();
}
```

📖 O legal, eh que assim voce consegue bater o olho na funcao chamada e saber oq é cada argumento, sem precisar acessar o method.

<br>

⚠️ Se for usar named arguments, use para todos os parâmetros.

## Default Arguments - Valor default de cada parametro

Voce pode definir um valor default para cada um dos parametros da function. 

Assim, esse parametro nao eh mais obrigatorio.

```kt
fun main(args: Array<String>) {
    
    val informacoes1 = informacoesPessoais();
    val informacoes2 = informacoesPessoais(age = 2);
    val informacoes3 = informacoesPessoais(name = "Ronaldo");
    val informacoes4 = informacoesPessoais(age = 222, name = "Ronaldo");
    val informacoes5 = informacoesPessoais("Ronaldo", 44);
}

fun informacoesPessoais(name: String = "usuario random", age: Int = 100): String {
    return """
        Nome: $name
        Age: $age
    """.trimIndent();
}
```

- 📖 Parâmetro com valor default → não precisa ser informado.
- 📖 Parâmetro sem valor default → é obrigatório informar.
