## Methods com e sem retorno
Assim como no Java, aqui temos methods com e sem retorno.


### Methods com retorno

```kotlin
fun somar(n1: Double, n2: Double): Double {
    return n1 + n2;
}

fun mensagemBonita(): String {
    return "Olá mundo!";
}

fun isEmpty(): Boolean{
    return true;
}
```

:book: Sempre informe o tipo do retorno. 

<br>
<br>

### Methods sem retorno *Unit*

Quando uma function não retorna nada, o tipo dela é `Unit` (equivalente ao `void` do Java).

```kotlin
fun printarMensagem(mensagem: String): Unit{
    println(mensagem);
}
```

📖 Por padrão, quando uma function/method nao retorna nada, o Kotlin já sabe que ela é Unit. Logo, voce nao precisa declarar o retorno desse Unit.

```kt
fun printarMensagem(mensagem: String) {
    println(mensagem);
}
```

## Named Arguments - Informando os argumentos pelo nome do parâmetro

Ao chamar uma function, podemos informar os argumentos pelo nome dos parâmetros, permitindo também alterar a ordem em que eles são passados.

```kt
fun main(args: Array<String>) {
    println(
        dadosPessoasFormatadinhos(
            age = 33,
            lastName = "naruto",
            firstName = "uzumaki"
        )
    )
}

fun dadosPessoais(
    firstName: String,
    lastName: String,
    age: Int
): String {
    return """
        Nome: $firstName
        Sobrenome: $lastName
        Idade: $age
    """.trimIndent();
}
```

:book: Quando temos muitos parâmetros, é uma boa prática passar os argumentos de forma nomeada.

## Default Arguments - Valor default de cada parametro

Voce pode definir um valor default para cada um dos parametros da function. 

Assim, esse parametro nao eh mais obrigatorio.

```kt
fun informacoes(
    name: String = "pessoa random",
    age: Int = 123
): String {
    return """
        Nome: $name,
        Age: $age
    """.trimIndent()
}
```

```kotlin
fun main(args: Array<String>){

    val info1 = informacoes();

    val info2 = informacoes(
        name = "goku"
    );

    val info3 = informacoes(
        age = 99
    );

    val info4 = informacoes(
        name = "sonic",
        age = 2
    );

    val info5 = informacoes(
        age = 2,
        name = "sonic"
    );
}
```

📖 Parâmetros com valor default → não precisa ser informado.

## Single-Expression Functions - Função com apenas 1 expressão

Quando a function tem apenas 1 expressao, voce pode escrever ela em apenas 1 linha.


```kt
//ex 1
fun mensagemBoasVindas1(name: String): String {
    return "Olá $name, seja bem vindo!"
}

fun mensagemBoasVindas2(name: String): String = "Olá $name, seja bem vindo!"



// Ex 2: 
fun somar(n1: Int, n2: Int): Int {
    return  n1 + n2;
}

fun somar (n1: Int, n2: Int): Int = n1 + n2;



// Ex 3: 
fun isEven(n: Int): Boolean {
    return n % 2 == 0;
}

fun isEven(n: Int): Boolean = n % 2 == 0;




// Ex 4: 
fun printar(): Unit {
    println("salve");
}

fun printar() = println("salve");
```

### Misturando uma funcao simples com uma expressao if else simples

Isso...

```kotlin
fun isNameLengthToBig(name: String): Unit{
    if(name.length > 10){
        println("nome gigante");
    }
    else{
        println("ok");
    }
}
```

Conseguimos reduzir pra isso:

```kotlin
fun isNameLengthToBig(name: String): Unit = if(name.length > 10) println("nome gigante") else println("ok");
```
