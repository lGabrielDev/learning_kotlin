# Anonymous Functions

Da mesma forma que podemos criar uma **Classe sem nome** (`Anonymous Class`), também podemos criar uma **função sem nome** (`Anonymous Function`).

Geralmente é utilizada quando precisamos de uma função temporária ou quando **queremos passar uma função como parâmetro para outra função**.

<hr>

## Funcao normal e funcao anonima (sem nome)

Funcao normal com nome:

```kotlin
fun boasVindas(nome: String): String {
    return "boas vindas $nome"
}
```

Anonymous Functions (funcao sem nome)

```kotlin
val boasVindas: (String) -> String = fun(nome: String): String {
    return "boas vindas $nome";
}

boasVindas("a");
```

<hr>

## Trabalhando com Anonymous Function da maneira tradicional

Aqui, vamos exemplificar usando as callback functions.

Criamos uma funcao, onde um dos parametros vai ser uma 'Anonymous Function'

```kotlin
fun funcaoPadrao(
    funcaoAnonima: (String) -> String //funcao anonima (funcao sem nome)
) {
    println("funcao padrao...")
    funcaoAnonima("goku");
}
```

Criamos uma funcao anonima e informamos como argumento

```kotlin
fun main(args: Array<String>) {
    
    val boasVindas: (String) -> String = fun(nome: String): String {
        return "boas vindas $nome";
    }
    
    funcaoPadrao(boasVindas);
}
```

<br>

## Trabalhando com lambda

Sempre que precisamos criar uma função sem nome (Anonymous Function), podemos utilizar uma Lambda como uma forma mais simples de escrevê-la. `{}`

```kotlin
val boasVindas: (String) -> String = { nome ->
    "boas vindas $nome";
}

funcaoPadrao(boasVindas);
```
