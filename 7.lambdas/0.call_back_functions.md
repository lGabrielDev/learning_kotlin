# Callback Functions

Normalmente, em uma funcao, estamos acostumados criar parametros com o datatype/tipo `String`, `Double`, `Long`, etc.

Porém, no Kotlin também podemos passar uma **funcao anonima (funcao sem nome)** como parametro.

Uma função passada como parâmetro é chamada de **Callback Function**. Informamos o argumento desse parametro, utilizando uma expressao lambda.

```kotlin
fun main(args: Array<String>) {
    boasVindas(
        "goku",
        { funcionario -> println("Parabens $funcionario") }
    )
}

fun boasVindas(
    novoFuncionario: String, //setando um parametro do tipo String
    printarParabens: (String) -> Unit //setando um parametro do tipo method/funcao
){
    println("Vamos dar as boas vindas...");
    printarParabens(novoFuncionario);
}
```

Nesse exemplo, a função `boasVindas()` tem um 'parametro especial', que eh do tipo funcao. Ou seja, um dos parametros é uma callback function.

> :book: Uma Callback é apenas um parâmetro que, ao invés de receber um valor (String, Int, etc.), recebe uma função anônima (funcao sem nome).

Sempre que estamos trabalhando com um parametro que eh do 'tipo' **method**, precisamos informar:

- Quais parâmetros ela recebe.
- Qual valor ela retorna.

`() -> Unit`

## Acostumando com a syntax do lambda

| Expressao Lambda          | Parâmetros recebidos |
|---------------------------|----------------------|
| `() -> Unit`              | Nenhum parâmetro     |
| `(String) -> Unit`        | Apenas 1 parâmetro   |
| `(Int, Double) -> Double` | Vários parâmetros    |
