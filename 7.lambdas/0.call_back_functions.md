# Callback Functions

Normalmente, em uma função, estamos acostumados a criar parâmetros com tipos como `String`, `Double`, `Long`, etc.

No Kotlin, também podemos criar parâmetros do **tipo função**. Os argumentos desses parâmetros são preenchidos com uma **função anônima**, utilizando uma **expressão Lambda**.

Uma função passada como parâmetro para outra função é chamada de **Callback Function**.

<hr>

## Entendendo na prática
No dia a dia, normalmente vamos passar esses argumentos para funções já prontas do Kotlin, como `filter`, `map`, `forEach`, `sortedBy`, etc.

A ideia aqui é criar algumas funcoes com parametros diferentes, para ficar mais claro.

<br>

### 1. Criando funcoes com parametros variados

Primeiro vamos criar as funcoes. Depois, vamos chamá-las e passar os argumentos das 2 formas:

- Dentro dos `()`
- Fora dos `()`

```kotlin
// funcao com 1 parametro do 'tipo funcao'
fun funcaoPrincipal1(
    funcaoCallback: () -> Unit
): Unit {
    funcaoCallback();
}

// funcao com os dois tipos de parametros (normais e do 'tipo funcao')
fun funcaoPrincipal2(
    n1: Double,
    n2: Double,
    funcaoPrintarResultadoCallBack: (Double) -> Unit
): Unit {
    val resultado: Double = n1 + n2;
    funcaoPrintarResultadoCallBack(resultado);
}

// funcao com 2 parametros do 'tipo funcao'
fun funcaoPrincipal3(
    n1: Double,
    n2: Double,
    funcaoPrintarCallback: (Double) -> Unit,
    funcaoPrintarCallbackVariasVezes: (Double) -> Unit
): Unit {
    val resultado: Double = n1 + n2;
    funcaoPrintarCallback(resultado);
    funcaoPrintarCallbackVariasVezes(resultado);
}

// funcao com 1 parametro do 'tipo funcao', que retorna alguma coisa
fun funcaoPrincipal4(
    funcaoTransformarNomeToUpperCase: (String) -> String,
    name: String
): String {
    return funcaoTransformarNomeToUpperCase(name);
}
```

<br>

### 2. Chamando essas funcoes e passando os argumentos

A regrinha sempre vai ser:

> :book: Sempre que o **último parâmetro** de uma função for do **tipo função**, o argumento pode ser informado dentro ou fora dos parênteses `()`. Geralmente utilizamos essa forma quando existe apenas um parâmetro do tipo função. Quando há vários parâmetros desse tipo, normalmente deixamos todos dentro dos `()` para facilitar a leitura.

#### Passando o ultimo parametro do 'tipo funcao' dentro dos `()`

Chame cada uma das 4 funcoes, passando os parametros do 'tipo funcao' dentro dos `()`.

```kotlin
fun main(args: Array<String>) {

    funcaoPrincipal1( { println("salve") } )

    funcaoPrincipal2 (
        2.0,
        3.0,
        { resultado -> println(resultado) }
    )

    funcaoPrincipal3(
        2.0,
        3.0,
        { resul ->
            println("callback 1")
            println(resul)
        },
        { resul ->
            println("callback 2")
            println(resul);
            println(resul);
            println(resul);
        },
    )

    funcaoPrincipal4(
        { name -> name.uppercase() },
        "goku"
    )
}
```

<br>

#### Passando o ultimo parametro do 'tipo funcao' fora dos `()`

```kotlin
fun main(args: Array<String>) {
    funcaoPrincipal1 { println("salve") } //funcao nao possui parametros normais, por isso removemos os `()`

    funcaoPrincipal2(
        2.0,
        3.0
    ){
        resultado -> println(resultado)
    }

    funcaoPrincipal3(
        2.0,
        3.0,
        { resul ->
            println("callback 1")
            println(resul)
        },
        { resul -> // quando temos várias funcoes do 'tipo funcao', fica mais legivel todas juntas mesmo
            println("callback 2")
            println(resul);
            println(resul);
            println(resul);
        },
    )

    funcaoPrincipal4(
        { name -> name.uppercase() }, // nao eh possivel pq o ultimo parametro não é do 'tipo funcao'
        "goku"
    )
}
```
