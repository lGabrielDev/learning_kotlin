# Conditions - if else

<hr>

## Syntax
Padrao como em qualquer outra linguagem

```kotlin
val age: Int = 22;

if(age > 18){
    println("Adulto liberado!");
}
else if(age == 17){
    println("quase lá...")
}
else{
    println("crianca nao pode!");
}
```

<hr>

## If reduzido, sem chaves
Quando tem apenas 1 expressão, podemos escrever sem as chaves `{}`

```kotlin
val age: Int = 22;
if(age > 18) println("Adulto liberado.") else println("criancao nao pode!");
```

<hr>

## If Else como expressão (retornando algum valor)

Nós conseguimos atribuir valor a uma variável dependendo de uma condição. Para isso, em outras linguagens usamos o operador ternário. No Kotlin não existe esse operador — usamos o `if/else` como expressão no lugar.

Expressao -> Retorna algum valor.

If Else como expressao -> If else vai retornar algum valor

```kotlin
val name: String = "goku";

//operador ternario
val nameIsNice: Boolean = if(name == "goku"){
    //fazer outras coias...
    true
}
else if(name == "naruto"){
    //fazer outras coias...
    true
}
else{
    //fazer outras coias...
    false
}
```
:warning: Trabalhando com if else como expressão, retornando um valor, nós não usamos a palavrinha `return`;


<br>

:book: Como vimos acima, quando tem apenas 1 expressão podemos deixar o if mais simples, sem as chaves `{}`. 


```kotlin
val nameIsNice: Boolean = if(name == "goku") true else if(name == "naruto") true else false;
```
