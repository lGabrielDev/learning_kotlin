# when (switch case do kotlin)

Usamos o when quando temos várias condições que seriam difíceis de organizar com vários if/else. Ele deixa o código mais simples e fácil de ler.


Ao inves de usar o `if else` padrao:

```kotlin
val n1 = 20;

if(n1 == 10){
    println("numero 10");
}
else if(n1 == 20){
    println("numero 20");
}
else{
    println("outros numeros");
}
```

Usamos o `when`

```kotlin
val n1 = 20;

when(n1){
    10 -> {
        println("numero 10");
    };
    20 -> {
        println("numero 20");
    }
    else -> {
        println("outros numeros");
    }
}
```

:book: Fica mais clean de ler.

Como tem apenas 1 expressao em cada 'case', podemos deixar assim:

```kotlin
when(n1){
    10 -> println("numero 10");
    20 ->  println("numero 20");
    else -> println("outros numeros");
}
```

## Usando when com várias condicoes
Quando temos várias condicoes diferentes, podemos deixar a condicao em cada 'case':

```kotlin
val age = 16;

when{
    age < 0 -> println("idade invalida");
    age == 18 -> println("adulto");
    age > 18 -> println("crescendo");
    else -> println("whatever");
}
```

<br>

## when como expressão (retornando algum valor)
Assim como fazemos com o if/else, o when também pode ser usado no lugar do operador ternário, que não existe no Kotlin.

- Expressao -> Retorna algum valor.
- `when` como expressao -> when vai retornar algum valor

```kotlin
val age = 44;

val categoria: String = when{
    age < 12 -> "criança"
    age < 18 -> "adolescente"
    age in 90..100 -> "velinho"
    else -> "adulto"
};
```

## Varios valores no mesmo case

```kotlin
val dia = 7;

when(dia){
    1, 7 -> println("Final de semana");
    2, 3, 4, 5, 6 -> println("Trabalho");
    else -> println("Dia invalido");
}
```


## Verificando o tipo do objeto com `is`

```kotlin
fun <T> verificarTipoVariable (data: T): String {
    return when(data){
        is String -> "tipo dela é String"
        is Int -> "tipo dela é Int"
        is Boolean -> "tipo dela é Boolean"
        else -> "outro tipo"
    }
}
```

## `when` pode verificar condições de várias formas
:book: Apenas leia

```kotlin
val age = 100;

when(age){
    !is String -> println("nao eh String")
    10, 20 -> println("10 e 20 legal");
    in 90..100 -> println("legal");
    else -> println("coisas");
}
```
