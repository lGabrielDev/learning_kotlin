## Anonymous Class

Normalmente, criamos uma Classe separada e depois criamos as instâncias / objetos dessa Classe.

**Anonymous Class** é uma class sem nome criada na mesma hora de instanciar um objeto.

> :book: Ou seja, criamos a **Classe + objeto** de uma vez só.

<br>

Não se preocupe com o porque de usar ela. Apenas saiba como fazer.

---
<br>

## Syntax

Criando uma class **Person** utilizando Anonymous Class.


```kotlin
fun main(args: Array<String>) {

    // criando um objeto e criando a classe no mesmo momento
    val p1 = object {

        var name: String? = null;
        var age: Int? = null;

        fun funcaoQualquer(): Unit {
            println("salve");
        }
    }

    p1.name = "sonic";
    p1.age = 44;

    println(p1.name)
    println(p1.age)
    p1.funcaoQualquer();
}
```
:book: Perceba que essa classe anonima, é como se fosse uma class **Person** criada da maneira tradcional kk

:warning: Em uma Anonymous Class, NÃO declaramos um constructor como fazemos em uma Classe normal. Isso porque a Classe e o objeto já são criados juntos naquele momento.

## Revisando alguns conceitos antes

### Interface

É um contrato que contem funcoes que vao ser usadas em algum momento. Essas funcoes ainda não possuem corpo. Ou seja, apenas sabemos oq elas fazem, mas não como elas vao fazer.


### Como utilizamos esas funcoes?

1. Existe uma interface

    ```kotlin
    interface Pagamento {
        fun pagar(value: Double): Unit;
    }
    ```

1. Criamos uma Classe e implementamos a Interface. Ou seja, essa Classe deseja utilizar as funcoes dessa interface.
1. Sobrescrevemos as funções e definimos o corpo delas.

    ```kotlin
    class PagamentoPix(): Pagamento {
        override fun pagar(value: Double) {
            println("Pagamento de R$ $value feito com sucesso!")
        }
    }
    ```

1. Criamos um objeto dessa Classe
1. Utilizamos a funcao

    ```kotlin
    fun main(args: Array<String>) {
        val p1 = PagamentoPix();
        p1.pagar(44.0)
    }
    ```

## Implementando uma Interface utilizando Anonymous Class

Nada demais, na prática é a mesma coisa. Vamos criar um objeto e definir a Classe desse cara ali mesmo.

O comportamento é igual ao de uma Classe normal. Como estamos implementando uma Interface, precisamos sobrescrever os métodos exigidos por ela.

```kotlin
fun main(args: Array<String>) {

    val pagamentoInsano = object : Pagamento {

        override fun pagar(value: Double) {
            println("Pago com sucesso!")
        }
    }

    pagamentoInsano.pagar(2.1);
}
```

> :book: A diferença é que não precisamos criar uma Classe separada para implementar `Pagamento`. Criamos a Classe anônima e o objeto ao mesmo tempo.
