## Anonymous Class

É uma Classe **sem nome**, criada no mesmo momento em que criamos um objeto dela.

Ao inves de criar uma Class em um arquivo separado, onde voce provavelmnte vai precisar criar varias instnacias dessa classe, voce pode criar uma classs rapidinha sla......melhroar isso

## Syntax

Criando uma class **Person** utilizando Anonymous Class.


```kotlin
fun main(args: Array<String>) {

    //criando um objeto e ao mesmo tempo criando a Class
    val p1 = object {

        var name: String? = null
            get() = field;
            set(value){ value = field};

        var age: Int? = null
            get() = field;
            set(value){ value = field};
    }

    p1.name = "sonic";
    p1.age = 44;

    println(p1.name)
    println(p1.age)
}
```

## Revisando alguns conceitos antes

### Interface

É um contrato que contem funcoes que vao ser usadas em algum momento. Essas funcoes ainda não possuem corpo. Ou seja, apenas sabemos oq elas fazem, mas não como elas vao fazer.


### Como utilizamos esas funcoes?

1. Existe uma interface

    ```kotlin
    interface Pagamento {
        fun pagar(value: Double): Unit;
    }
    ```

1. Criamos uma Classe e implementamos a Interface. Ou seja, essa Classe deseja utilizar as funcoes dessa interface.
1. Sobrescrevemos as funções e definimos o corpo delas.

    ```kotlin
    class PagamentoPix(): Pagamento {
        override fun pagar(value: Double) {
            println("Pagamento de R$ $value feito com sucesso!")
        }
    }
    ```

1. Criamos um objeto dessa Classe
1. Utilizamos a funcao

    ```kotlin
    fun main(args: Array<String>) {
        val p1 = PagamentoPix();
        p1.pagar(44.0)
    }
    ```
