# Anonymous Class

Uma Anonymous Class é uma classe sem nome, criada diretamente no momento em que instanciamos um objeto.

Ela é útil quando precisamos criar uma implementação temporária de uma classe abstrata ou de uma interface, que será utilizada apenas uma vez.

> :book: No dia a dia do Kotlin ela não é tão comum quanto as lambdas, mas é importante saber o que é e conseguir ler esse tipo de código quando ele aparecer.


Geralmente, uma Anonymous Class herda de uma classe abstrata ou implementa uma interface.

<hr>

## Herdando uma classe

### Maneira tradicional

1. Digamos que ja existe uma Classe que queremos herdar

    ```kotlin
     abstract class Conta (
        val numero: String,
        var saldo: Double
    ){
        abstract fun funcaoQualquer(): Unit;
    }
    ```
   
    > classe abstract já eh `open` por padrão.

<br>

2. Criamos uma classe filha que vai herdar

    ```kotlin
    class ContaCorrente() : Conta("123", 100.0) {
        //definindo o corpo
        override fun funcaoQualquer() {
            // algo...
        }
    }
    ```

<br>

3. Usamos os methods e attributes dessa Classe

    ```kotlin
    fun main(args: Array<String>) {
        val c1: ContaCorrente = ContaCorrente();
        c1.numero;
        c1.saldo;
        c1.funcaoQualquer();
    }
    ```

<br>

### Anonymous Class

Ao invés de fazer todo aquele processo acima, vamos criar a classe ao mesmo tempo que instanciamos um objeto dela.

```kotlin

fun main(args: Array<String>) {
    
    //criamos uma classe anônima e já instanciamos um objeto dela
    val c1 = object : Conta (
        "123",
        100.0
    )
    {
        override fun funcaoQualquer() {
            // algo...
        }
    }
    c1.numero
    c1.saldo
    c1.funcaoQualquer();
}
```

<hr>

## Implementando uma interface

Bem parecido...

### Maneira tradicional

1. Digamos que ja existe uma Interface que queremos implementar

    ```kotlin
    interface MethodsConta{
        fun depositar();
    
        fun sacar(){
            println("sacando...")
        }
    }
    ```

<br>

2. Criamos uma classe que implementa a interface

    ```kotlin
    class ContaCorrente(): MethodsConta{
        override fun depositar() {
            //algo...
        }
    }
    ```

<br>

3. Usamos os methods e attributes dessa Classe

    ```kotlin
    fun main(args: Array<String>) {
        val c1: ContaCorrente = ContaCorrente();
        c1.depositar();
        c1.sacar();
    }
    ```

<br>

### Anonymous Class

Ao invés de fazer todo aquele processo acima, vamos criar a classe ao mesmo tempo que instanciamos um objeto dela.

```kotlin
fun main(args: Array<String>) {
    val c1 = object : MethodsConta {
        override fun depositar() {
            // algo...
        }
    }
}
c1.sacar()
c1.depositar()
```

> :book: Quando você encontrar object :, saiba que estamos criando uma classe anônima e instanciando um objeto dela no mesmo momento.

<hr>

## Resumindo... O que é uma Anonymous Class?

É uma classe sem nome, onde voce cria essa classe e já instancia um objeto no mesmo momento.

### Criando uma classe normal, com nome

```kotlin
class Person(
    var name: String
){
    fun nomeUpper(): String{
        return this.name.uppercase();
    }
}

fun main(args: Array<String>) {
    val p1: Person = Person("naruto");
}
```

<hr>

## Relembrando

- `class ClasseQualquer : Conta()`  -> está herdando uma Classe
- `class ClasseQualquer : AlgumaInterface` -> está implementando uma Interface
