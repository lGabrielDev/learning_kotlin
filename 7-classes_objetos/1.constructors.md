# Constructors

O constructor é o primeiro method que eh chamado assim que criamos um objeto.

```kotlin
var p1: Person = Person();
```


No Kotlin, nós separamos os contrutores em 2:

- Constructor primário
- Constructors secundários


<hr>


## Primary Constructor
É o constructor principal do Kotlin. É declarado direto na assinatura da classe.

O legal eh que aqui conseguimos criar os attributes / properties direto nele. Não precisamos mais fazer aquela atribuição de attribute e parametro igual no java... `this.name = name`

```kotlin
class Person constructor(var name: String, var age: Int){}
```

:warning: Para criar os attributes / propriedades direto nesse constructor primário, você precisa criar os parametros com `var` ou `val`. Do contrário serão apenas parâmetros.


<br><br>

### Init block
Como o primary constructor não tem 'corpo', pois eh declarado lá em cima da Class, o corpo dele são os blocos `init{}`.

```kotlin
fun main(args: Array<String>){
    var p1: Person = Person("naruto", 222);
}

class Person constructor(
    var name: String,
    var age: Int
){

    init{
        //por baixo dos panos os attributes recebem os parametros
        // this.name = name
        
        println("init 1");
        println("Name: ${this.name}");
        println("Age: ${this.age}");
    }

    init{
        println("init 2");
    }
}
```

:book: Sempre que tiver um bloco `init`, sei que são os 'corpos' do primary constructor. A ordem de execução deles eh de cima pra baixo padraozinho.

<hr>
<br>

### Constructor vazio

Aqui no Kotlin o constructor vazio eh criado em 2 situações:

1. Igual ao Java... Quando não criamos nenhum constructor.
2. Quando criamos o constructor primário e setamos todos os parâmetros com um valor default.

    ```kt
    //Todos os parametros tem valor default setado... Eh criado um constructor vazio :thumbsup:
    class Person constructor(
        var name: String = "",
        var age: Int = 0 
   ){}
    ```

<hr>
 

## Secondary Constructors
Assim como no Java, aqui podemos ter mais de 1 constructor. Além do constructor primário, podemos ter vários constructors secundários. Assim, conseguimos criar objetos de diferentes formas.

```kotlin
//constructor primario
class Person constructor(
    //cria os attributes e faz a atribuição -> this.attribute = parametro
    val name: String?,
    val age: Int?
) {
    //corpo do constructor primário
    init{
        println("primario chamado");
    }

    //constructor secundário
    constructor() : this(null, null) {
        println("secundario chamado");
    }
}
```

:book: O constructor secundário SEMPRE chama o constructor primário antes de executar o próprio código.

<br>

:worm: Debugando, você vai perceber que:

- Antes de executar o proprio código, o constructor secundário chama o constructor primário

- Constructor primário cria seus attributes, faz a atribuição `this.name = name` e executa seus corpos `init`.

- Constructor secundário executa seu código


<br>

:bulb: Geralmente o pessoal usa apenas o constructor primário.
