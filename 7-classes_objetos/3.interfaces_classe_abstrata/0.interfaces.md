# Interfaces
Interfaces são contratos que as classes devem seguir. Nela, existem methods abstratos (methods sem corpo) e methods normais com corpo.

A ideia é que o contrato defina a assinatura dos methods (os parametros e os retornos).

Pensando num exemplo real, imagina o seguinte:

:construction_worker: Seu chefe precisa criar alguns methods para o projeto. Ele sabe exatamente oque precisa passar como parametro e qual o retorno de cada method, mas não quer mexer no corpo desses caras. Ele vai botar um dev para trabalhar nessa 'historia'.

<hr>

## Como usamos um method de uma interface:

Seguindo o exemplo acima, vamos imaginar que somos o dev que precisa criar o corpo deses methods.

O fluxo completo da criação e utilização desses methods vai ser:

<br>


1. Seu chefe cria a interface

    ```kotlin
    interface InterfaceChefe {
        //method abstrato 1
        public abstract fun somarDoisNumeros(n1: Int, n2: Int): Int;
    
        //method abstrato 2
        fun printarQualquerBesteria(qualquerBesteira: String): Unit;
    
        //method normal com corpo
        fun boasVindas(nome: String): String {
            return "Boas vindas $nome";
        }
    }
    ```
   
    > :book: Perceba que numa Interface podemos ter tanto methods abstratos quanto methods com corpo.
    
    > :book: Por padrão, todo method dentro de uma interface tem o modificador `public` e eh `abstract`.

<br>

2. Nós como dev, criamos a Classe e implementamos essa interface. Uma vez implementada, fechamos um contrato com a interface e somos OBRIGADOS a definir o corpo dos methods abstratos (methods que ainda não possuem corpo).

    ```kotlin
    class ClasseQualquer (): InterfaceChefe {
   
        override fun somarDoisNumeros(n1: Int, n2: Int): Int {
            return n1 + n2;
        }
    
        override fun printarQualquerBesteria(qualquerBesteira: String) {
            println(qualquerBesteira);
        }
    }
    ```
   
     > :book: Apenas somos obrigados a sobreescrever os methods abstratos. Os methods normais com corpo temos a opção de sobreescrever ou não. 
   
<br>
 

3. Instanciamos a Classe e usamos o method.

    ```kotlin
    fun main(args: Array<String>) {
   
        val objeto1: ClasseQualquer = ClasseQualquer();
        objeto1.somarDoisNumeros(1,2);
        objeto1.printarQualquerBesteria("a");
        objeto1.boasVindas("goku");
    }
    ```

## Uma classe pode implementar várias interfaces

:pencil2: Crie mais uma interface, agora temos 2 interfaces, e implemente em alguma Classe.

```kotlin
class ClasseQualquer (): InterfaceChefe, IntefaceInsana {
    
    //methods abstratos da interface 1
    override fun somarDoisNumeros(n1: Int, n2: Int): Int {
        return n1 + n2;
    }

    override fun printarQualquerBesteria(qualquerBesteira: String) {
        println(qualquerBesteira);
    }

    //methods abstratos da interface 2
    override fun methodInsano(): Boolean {
        TODO("Not yet implemented")
    }
}
```
