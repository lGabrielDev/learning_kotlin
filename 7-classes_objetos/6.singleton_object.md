# Singleton Object

Singleton é um padrão de projeto que garante que apenas uma determinada Classe terá **apenas 1 instância** em toda a aplicação.

## Por quê usar?
📖 Usamos singleton quando queremos que um objeto seja **único** na aplicação — garantindo que todos os lugares do código acessem o mesmo objeto com os mesmos valores.

---

## Syntax

:book: Em Kotlin, usamos a keyword `object` para criar um singleton — ele é ao mesmo tempo a classe e a instância.

```kotlin
object ConfiguracaoPadrao {
    
    val

    var urlApi: String = "https://api.itau.com.br";
    val timeout: Int = 30;
    val ambiente: String = "producao";


    fun subirServidor(): Unit {
        println("servidor online");
    }
}
```
lemrabdno q podemos criar constantes dentro dde um singleton obnjeto.

:book: Como `object` é uma classe também, ela pode ter attributes e methods como qualquer classe. Pode herdar, implementar interfaces etc...

---

## Diferenca de um Singleton Object para uma Classe abstrata

- **Classe abstrata** → foco em herança — define uma base pra outras classes herdarem.


- **Singleton** → foco em instância única — um objeto único pra toda a aplicação.
