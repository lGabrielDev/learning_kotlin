# Properties

Aqui no Kotlin, os attributes de uma Class são chamados de `properties`.


Podemos criar essas propriedades / attributes de 2 formas:

1. Criando igualzinho ao Java:
    ```kt
    class Person(){
        //attributes
        val name: String? = null;
        val age: Int? = null;
    }
    ```

   ⚠️ Lembrando que dessa forma, esses attributes PRECISAM ser inicializados com algum valor.

<br>

2. Criando direto no constructor primário. (A forma mais usada)
    ```kt
    class Person constructor(
       var name: String,
       var age: Int
   ){}
    ```

    ⚠️ Para que sejam criados como attributes, use `var` ou `val` no constructor. Sem isso, serão apenas parâmetros.

    <br>

## Getters and Setters


Sempre que você cria propriedades / attributes numa class, o kotlin automaticamente cria um get() e set() pra cada propriedade.


Esses getters e setters seguem essa syntax:

```kt
class Person () {

    var name: String? = null

        get(){ // Não precisamos informar o tipo de retorno do get(), pois o Kotlin já sabe o tipo da propriedade.
            return field;
        }

        set(value){ // Também não precisamos informar o tipo do value no set(), pois ele será do mesmo tipo da propriedade.
            field = value;
        }

}
```

> 📖 `field` representa a propriedade que o get e set fazem parte.

<br>


Como o getter retorna um valor, podemos deixar ele mais simples:


```kt
class Person {

    var name: String? = null

        get() = field;

        set(value) {  
            field = value
        };
}
```

<br>
<br>

### Chamando o getter e o setter

```kt
fun main(args: Array<String>){

    val p1: Person = Person();

    p1.name = "goku"; //chamando o setter
    println(p1.name); //chamando o getter

}
```

### Personalizando o getter e o setter de uma propriedade / attribute

Por padrão, o Kotlin cria os getters e setters automaticamente. Só crie-os manualmente quando precisar personalizar o comportamento.


```kt
class Person {
    var name: String? = null
    //getters e setters criados automaticamente
}


class Person {
    var name: String? = null

        get(){
            return field?.uppercase() ?: "nao tem valor";
        }

        set(value){
            field = value;
            println("valor alterado com sucesso!");
        }
}
```

:warning: Só é possível personalizar os getters e setters de cada propriedade, se elas forem declaradas no escopo da class, fora do constructor primário.

#### Como o Kotlin sabe qual eh o getter e setter de cada propriedade?

Ele sabe pela identação e pela ordem.

Se têm um getter e setter de baixo da propriedade, sabemos que pertencem á ela.

```kt
class Person {

    //propriedade / attribute 1
    var name: String? = null
        get() = field;
        set(value) {
            field = value
        }

    //propriedade / attribute 2
    var age: Int? = null
        get() = field;
        set(value){
            field = value
        }

    //propriedade / attribute 3
    var favoriteColor: String? = null
        get() = field
        set(value){
            field = value;
        }
}
```
