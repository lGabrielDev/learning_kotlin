## Companion Object

É um objeto único que fica dentro de uma Classe.

> :book: É parecido com o `static` do Java. Podemos acessar suas propriedades e funções diretamente através da Class e não das suas instancias.

```kotlin
class Customer(
    val name: String,
    val age: Int
){

    init{
        quantidadeCustomersCriados ++;
    }


    //todas as propriedades e funcoes aqui dentro sao acessados de forma static - Através da Class
    companion object{
       var quantidadeCustomersCriados = 0;
        
        fun funcaoAleatoria(){
            println("salve"); 
        }
    }
}
```


```kotlin
fun main(args: Array<String>) {

    val p1 = Customer("goku", 44);
    val p2 = Customer("sonic", 33);

    Customer.quantidadeCustomersCriados;
    Customer.funcaoAleatoria();

    // por baixo dos panos, o kotlin acessa o objeto dentro da class
    println(Customer.Companion.quantidadeCustomersCriados);
    println(Customer.Companion.funcaoAleatoria());

}
```
