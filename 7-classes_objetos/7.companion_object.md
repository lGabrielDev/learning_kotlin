# companion object

Um `companion object` está vinculado a uma classe, permitindo-nos definir attributes e methods `static` semelhantes aos do Java.

Ou seja, os attributes e methods dentro de um companion objeto **são chamados através da própria classe** e não das suas instancias.

## Syntax

```kotlin
data class Person (
    val name: String,
    val age: Int
){

    companion object{

        val nomeBanco = "ITAU";
        val enderecoBanco = "CEIC ITAU";

        fun toStringNaMao(): String {
            return "$nomeBanco e $enderecoBanco"
        }
    }
}
```

> ⚠️ O `companion object` não consegue acessar os attributes e methods da classe em que está.
>
> Como é chamado de forma estática, nenhuma instância é informada — então não tem como saber a qual objeto esses attributes pertencem.
> 

```kotlin
fun main(args: Array<String>) {

    //chamando de maneira static
    Person.nomeBanco;
    Person.enderecoBanco;
    Person.toStringNaMao();

    //por debaixo dos panos
    Person.Companion.nomeBanco;
    Person.Companion.enderecoBanco;
    Person.Companion.toStringNaMao();
}
```

## Nomeando um companion object

É possível dar um nome para sua companion object. Geralmente o pessoal não faz isso, mas é legal saber que existe.



```kotlin
companion object ClasseBolada {

    val nomeBanco = "ITAU";
    val enderecoBanco = "CEIC ITAU";

    fun toStringNaMao(): String {
        return "$nomeBanco e $enderecoBanco"
    }
}
```

```kotlin
fun main(args: Array<String>) {

    //ninguem usa assim...
    Person.ClasseBolada.nomeBanco;
    Person.ClasseBolada.enderecoBanco;
    Person.ClasseBolada.toStringNaMao();
    
    //maneira mais usada
    Person.nomeBanco;
    Person.enderecoBanco;
    Person.toStringNaMao();
}
```
