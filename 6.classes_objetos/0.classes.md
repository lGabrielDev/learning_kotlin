# Classes


## Criando uma classe e criando um objeto

A syntax no Kotlin para criar um objeto vai ser assim:

```kotlin
class Person {

}
```

📖 Em Kotlin o modificador padrão é **public**. Ou seja, se não informar o modificador da classe ou da function, vai ser sempre public.

<br>


```kotlin
fun main(args: Array<String>){
    val p1: Person = Person();
    val p2 = Person(); //usando inferencia
}
```

📖 Para instanciar classes / criar objetos no Kotlin nós não precisamos usar a keyword `new`.

## Criando uma class no Java e no Kotlin

Java:

```java
public class Person {

    //attributes
    private String name;

    //constructors
    public Person(){}

    public Person(String name){
        this.name = name;
    }

    //getters and setters
    public String getName(){
        return this.name;
    }

    public void setName(String name){
        this.name = name;
    }

    //toString()
    @Override
    public String toString() {
        return "Person{" +
                "name='" + name + '\'' +
                '}';
    }

    //equals()
    @Override
    public boolean equals(Object o) {
        if (o == null || getClass() != o.getClass()) return false;
        Person person = (Person) o;
        return Objects.equals(name, person.name);
    }
}
```
