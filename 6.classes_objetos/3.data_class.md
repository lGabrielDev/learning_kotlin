# Data Class

A keyword `data` gera automaticamente alguns methods essenciais para essa Class.

Que seriam:

| Método | O que faz                                                       |
|---|-----------------------------------------------------------------|
| `toString()` | Retorna uma String com os valores das propriedades / attributes |
| `equals()` | Compara se dois objetos são iguais pelos valores                |
| `hashCode()` | Gera um número que representa o objeto                          |
| `copy()` | Cria uma cópia do objeto, podendo alterar alguns attributes     |
| `componentN()` | Permite desestruturar o objeto em variáveis separadas           |

<hr>

## Syntax

```kotlin
data class Person(val name: String){
    //toString()
    //equals()
    //hashCode()
    //copy()
    //componentN()
}
```

<hr>


## Regrinhas

⚠️ Uma `data class` deve ter pelo menos 1 parâmetro no constructor primário. Sem isso, não faz sentido — os métodos gerados (`toString()`, `equals()`, etc) não teriam nenhuma property pra considerar.

<br>

⚠️ Todos os methods sobreescritos pelo `data class` só vão considerar os attributes criados no constructor primário.

<hr>

## Quando usar `data Class` ou uma `class normal`?

- `data class` -> Quando a classe representa dados (DTO, Entidades, etc)


- `class normal` --> Quando é uma classe de regra de negócio, uma service, controller etc...
