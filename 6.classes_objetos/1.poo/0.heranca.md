# Herança

Herança é quando uma Classe herda os attributes e methods de uma outra Classe.

Quando várias classes compartilham os mesmos attributes e methods, criamos uma classe pai com esses elementos e as classes filhas herdam tudo automaticamente — evitando repetição de código.

<hr>

## Classe Pai `Any`

No Java, todas as classes são filhas da classe pai `Object`.

No Kotlin é parecido — toda classe é filha da classe `Any`. Ou seja, todas as classes herdam os methods da `Any`.

Diferente da classe `Object` do Java, a `Any` é mais reduzida e tem apenas 3 methods:

- `equals()`   → Compara se dois objetos são iguais (por padrão compara referência de memória / hashCode).
- `hashCode()` → Retorna um hash representando o objeto.
- `toString()` → Retorna uma String com todos os attributes, representando o objeto.

<hr> 

## Syntax

```kotlin
class Person (val name: String): Any() {}
```

> :book: É igualzinho ao implementar uma interface. A diferenca eh que, como se trata de uma class, usamos o `()`

<hr>

## Palavras reservadas `final` e `open`

Antes de colocar a mão na massa é importante aprender alguns conceitos.

- Por padrão, toda **classe** é `final` → não pode ser herdada. Usamos `open` pra liberar.
- Por padrão, todo **method** é `final` → a classe filha herda mas não pode sobrescrever. Use `open` pra liberar.
- **Attributes** são herdados normalmente — não precisam de `open`.

### Liberando uma class para poder ser herdada

A ideia aqui é libera uma classe `final`, não pode ser herdada, para `open`. Assim, ela consegue dar seus attributes e methods para outras classes.

<br>

1. Crie uma classe Pai `Conta` e libere ela pra heranca, usando o `open`.

    <br>

   Não pode ser herdada
    ```kotlin
    final class Conta (
        val titulo: String,
        val saldo: Double
    ){
        //funcao usada para todos os tipos de conta
        fun sacarValorNoCaixaEletronico(valor: Double): String {
        return "R$ $valor retirado com sucesso!"
        }
    }
    ```

   Aberta para herança
    ```kotlin
    open class Conta (
        val titulo: String,
        val saldo: Double
    ){
        //funcao usada para todos os tipos de conta
        fun sacarValorNoCaixaEletronico(valor: Double): String {
        return "R$ $valor retirado com sucesso!"
        }
    }
    ```

   > :warning: Não podemos usar `data` com `open`.

<br>

2. Crie 3 classes filhas que herdem os attributes e methods da classe pai `Conta`.

    <br>

    - `ContaCorrente`
    - `ContaSalario`
    - `ContaPoupanca`

    <br>

    ```kotlin
    class ContaSalario (
        titulo: String,
        saldo: Double,
        val diaDePagamento: Int //attribute exclusivo dessa classe
    ): Conta(titulo, saldo) {}
    
    class ContaCorrente(
        titulo: String,
        saldo: Double,
        val limiteLIS: Double //attribute exclusivo dessa classe
    ): Conta(titulo, saldo) {}
    
    class ContaPoupanca(
        titulo: String,
        saldo: Double,
        val taxaRendimento: String //attribute exclusivo dessa classe
    ): Conta(titulo, saldo) {}
    ```

   > :book: Por baixo dos panos é igualzinho ao Java — a classe filha chama o constructor da classe pai via `super()`.
   
    <br>

    1. A classe filha é instanciada e seus parâmetros exclusivos são criados
    2. O constructor da classe pai é chamado via `super()` e seus attributes são inicializados
    3. A classe filha tem seus proprios attributes e herda tudo da classe pai


<br>

3. Instancie / crie objetos dessas classes filhas

    ```kotlin
    fun main(args: Array<String>) {
        val c1: ContaSalario = ContaSalario("conta salario", 200.0, 15);
        val c2: ContaCorrente = ContaCorrente("conta corrente", 500.0, 100.0);
        val c3: ContaPoupanca = ContaPoupanca("conta poupanca", 750.20, "40%");
    
        c1.titulo; //herdado
        c1.saldo; //herdado
        c1.sacarValorNoCaixaEletronico(2000.0) + "\n"; //herdado
        c1.diaDePagamento; //exclusivo
    
        c2.titulo; //herdado
        c2.saldo; //herdado
        c2.sacarValorNoCaixaEletronico(2000.0) + "\n"; //herdado
        c2.limiteLIS; //exclusivo
    
        c3.titulo; //herdado
        c3.saldo; //herdado
        c3.sacarValorNoCaixaEletronico(2000.0) + "\n"; //herdado
        c3.taxaRendimento; //exclusivo
    }
    ```
