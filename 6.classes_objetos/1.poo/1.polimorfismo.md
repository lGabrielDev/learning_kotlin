# Polimorfismo


## Sobrecarga (overload)

Podemos ter methods com o mesmo nome, desde que tenham parâmetros diferentes:

- Quantidade de parâmetros diferente
- Tipo de parâmetros diferente


```kotlin
fun gerarTexto(): String {
    return "texto tal";
}

fun gerarTexto(nome: String): String {
    return "texto tal";
}

fun gerarTexto(nome: String, nome2: String): String {
    return "texto tal";
}

fun gerarTexto(age: Int): String {
    return "texto tal";
}
```
