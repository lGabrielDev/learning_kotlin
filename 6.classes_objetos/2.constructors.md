# Constructors

O constructor é o primeiro method que eh chamado assim que criamos um objeto.

```kotlin
var p1: Person = Person();
```

<hr>
<br>

## Primary Constructor
É o constructor principal do Kotlin. É declarado direto na assinatura da classe.

```kotlin
class Person constructor(var name: String, var age: Int){}


fun main(args: Array<String>){
    
    var p1: Person = Person("naruto", 222);
    
}
```

:warning: Lembrando que para criar os attributes / propriedades direto nesse constructor primário você precisa criar os parametros com `var` ou `val`. Do contrário serão apenas parâmetros.


<br><br>

### Init block
Como o primary constructor não tem 'corpo', pois eh declarado lá em cima da Class, o corpo dele são os blocos `init{}`.

```kotlin
fun main(args: Array<String>){
    var p1: Person = Person("naruto", 222);
}

class Person constructor(var name: String, var age: Int){

    init{
        println("init 1");
        println("Name: ${this.name}");
        println("Age: ${this.age}");
    }

    init{
        println("init 2");
    }
}
```

:book: Sempre que tiver um bloco `init`, sei que são os 'corpos' do primary constructor. A ordem de execução deles, eh de cima pra baixo padraozinho.

### Constructor vazio

Aqui no Kotlin o constructor vazio eh criado em 2 situações:

1. Igual ao Java... Quando não criamos nenhum constructor.
2. Quando criamos o constructor primário e setamos todos os parâmetros com um valor default.

```kt
//Todos os parametros tem valor default setado... Eh criado um constructor vazio :thumbsup:
class Person constructor(var name: String = "", var age: Int = 0 ){}


//Falta valor default em algum parametro... O constructor vazio não eh criado :thumbsdown:
class Person constructor(var name: String = "", var age: Int ){}
```

## Secondary Constructors
Assim como no Java, aqui podemos ter mais de 1 constructor. Além do constructor primário, podemos ter vários constructors secundários. Assim, conseguimos criar objetos de diferentes formas.

```kotlin
//constructor primario:
class Person constructor(var name: String, var age: Int){

    //construtor secundario 1:
    constructor() : this("nome do constructor 1", 1) {
        println("constructor 1 foi chamado");
    }

    //construtor secundario 2:
    constructor(nameInsano: String) : this("nome do constructor 2", 2) {
        println("constructor 2 foi chamado");
    }
}

fun main(args: Array<String>){

    var p1: Person = Person("Batman", 33);  //constructor primario
    var p2: Person = Person();  //constructor secundario 1
    var p3: Person = Person("Coringa"); //constructor secundario 2

}
```

:warning: Todo constructor secundary é obrigado a chamar o constructor primário, usando o `this()`. Ou seja, mesmo que a pessoa crie o objeto usando um constructor secundário, o constructor primário é executado de toda forma.

## Entendendo a ordem dos constructors

Ao criar um objeto, mesmo que o constructor chamado for um secondary constructor... A ordem sempre vai ser essa:

- Antes de executar seu proprio código, o constructor secundário chama o constructor primário

- Constructor primário cria seus attributes e executa seus corpos `init`.

- Constructor secundário executa seu código

```kotlin
class Person(var name: String, var age: Int){

    //blocos init -> Corpos do constructor primario
    init{
        println("init 1");
    }
    init{
        println("init 2");
    }

    //secondary constructors
    constructor() : this("teste", 0){
        println("secondary constructor 1");
    }
    constructor(name: String) : this(name, 0){
        println("secondary constructor 2");
    }
    constructor(age: Int) : this("qualquer", age){
        println("secondary constructor 3");
    }
}

fun main(args: Array<String>){
    var p1: Person = Person(44);
}
```
