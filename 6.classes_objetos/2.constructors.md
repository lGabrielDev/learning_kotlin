# Constructors

O constructor é o primeiro method que eh chamado assim que criamos um objeto.

<hr>
<br>

## Constructor vazio

Assim como no Java, se não criarmos nenhum constructor, automaticamente o Kotlin cria um constructor vazio para nós.

```kt
class Person{

}


fun main(args: Array<String>){

    var p1: Person = Person();

}
```
