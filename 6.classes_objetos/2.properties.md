# Properties

Aqui no Kotlin, os attributes de uma Class são chamados de `properties`.


Podemos criar essas propriedades / attributes de 2 formas:

1. Criando igualzinho ao Java:
    ```kt
    class Person {
        var name: String = "";
        var age: Int? = null;
    }
    ```

   ⚠️ Lembrando que dessa forma, esses attributes DEVEM ser inicializados com algum valor.

<br>

1. Criando direto no constructor primário
    ```kt
    class Person constructor(var name: String, var age: Int){}
    ```

    ⚠️ Para que sejam criados como attributes, use `var` ou `val` no constructor. Sem isso, serão apenas parâmetros.

    <br>

## Getters and Setters


Sempre que voce cria uma propriedade / attribute em uma class, o kotlin automaticamente cria o getter e setter dessa propriedade.

```kotlin
//1. Criando do Jeito "Java"
class Person(){
    //attributes
    var name: String? = null; // criamos o attribute / property do jeito "Java", somos obrigados a inicializar.
    
    //getter and setter são criados automaticamente
}



// 2. Criando no constructor primario
class Person(var name: String?){
    //getter and setter são criados automaticamente
}

```


No Kotlin, esses getters e setters seguem essa syntax:

```kt
class Person {

    var name: String? = null

        get(){ // não precisamos informar o datatype desse retorno porque o Kotlin já sabe qual eh. Ele lembra do datatype porque informamos na criação dessa propriedade / attribute.
            return field;
        }

        set(value){ // não precisamos informar o datatype desse parâmetro porque o Kotlin já sabe qual eh. Ele lembra do datatype porque informamos na criação dessa propriedade / attribute.
            field = value;
        }
}
```

📖 `field` eh o proprio campo / propriedade que estamos trabalhando. Seria como um `this.name` no Java. Como o get() e set() ficam logo abaixo da propriedade, o field já diz respeito ao proprio campo.

<br>


Como o getter retorna um valor, podemos deixar ele mais simples:


```kt
class Person {

    var name: String? = null

        get() = field;

        set(value) {  
            field = value
        };
}
```

<br>
<br>

### Chamando o getter e o setter

```kt
fun main(args: Array<String>){

    val p1: Person = Person();

    p1.name = "goku"; //chamando o setter
    println(p1.name); //chamando o getter

}
```

### Personalizando o getter e o setter de uma propriedade / attribute

Se você não quer personalizar os getters e setters, eh só não criá-los. Deixa que o Kotlin cria para você.

Se você precisa personalizar o getter ou o setter, aí sim vc precisa criar esses methods.



```kt
class Person {
    var name: String? = null
    //getters e setters criados automaticamente
}


class Person {
    var name: String? = null

        get(){
            return field?.uppercase() ?: "nao tem valor";
        }

        set(value){
            field = value;
            println("valor alterado com sucesso!");
        }
}
```

#### Como o Kotlin sabe qual eh o getter e setter de cada propriedade?

Ele sabe pela identação e pela ordem.

Se têm um getter e setter de baixo da propriedade, sabemos que pertencem á ela.

```kt
class Person {

    //propriedade / attribute 1
    var name: String? = null
        get() = field;
        set(value) {
            field = value
        }

    //propriedade / attribute 2
    var age: Int? = null
        get() = field;
        set(value){
            field = value
        }

    //propriedade / attribute 3
    var favoriteColor: String? = null
        get() = field
        set(value){
            field = value;
        }
}
```

### E se eu criar os attributes no constructor primário? Como personalizo os getters e setters?

Não é possível diretamente. Para personalizar, declare o parâmetro no constructor **sem** `var` ou `val`, e crie a property no corpo da classe:

```kt
class Person(name: String){ // sem 'var'. Apenas criamos o parametro
    //attributes
    var name: String? = null
        get(){
            return field?.uppercase() ?: null;
        }
        set(value){
            field = value?.uppercase() ?: null;
        }

    //primary constructor
    init{
        this.name = name;
    }
}
```
