# Kotlin

O kotlin funciona igualzinho ao Java.

Quando a aplicação é executada, a JVM procura primeiro o **method main** para iniciar seu programa.

<br>

Java

```java
public class Main {
   public static void main(String[] args){
      System.out.println("Salve");
   }
}
```

<br>

Kotlin

```kt
fun main(args: Array<String>){
   println("Salve!");
}

//ou simplesmente

fun main(){
   println("Salve!");
}
```

💡 Nas duas linguagens, o method main recebe como parametro uma Array de String.

<hr>

## `print` and `println`

Padrao java

```kt
fun main(){
   print("Salve!"); // Não pula linha
   println("Salve!"); // Dá um \n no final
}
```
