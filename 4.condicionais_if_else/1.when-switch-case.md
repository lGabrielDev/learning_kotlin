# when (switch case do kotlin)

Usamos o when quando temos muitas condições if else... Aqui, fica mais fácil de ler o código.

<br>

Ao inves de usar o if else padrao:

```kotlin
val numerInsano: Int = 0;

if(numerInsano == 0){
    println("numero 0")
    //faz outras coisinhas...
}
else if(numerInsano == 1){
    println("numero 1");
    //faz outras coisinhas...
}
else{
    println("numero qualquer");
    //faz outras coisinhas...
}
```

<br>

Usamos o `when`


```kotlin
when(numerInsano){
    0 -> {
        println("numero 0 bolado");
        //fazer coisas...
    }
    1 -> {
        println("numero 1 bolado");
        //fazer coisas...
    }
    else -> {
        println("qualquer numero");
        //fazer coisas...
    }
}
```

:book: Fica mais clean de ler.


Como tem apenas 1 código em cada 'case', podemos deixar assim:

```kotlin
when(numerInsano){
    0 -> println("numero 0 bolado");
    1 -> println("numero 1 bolado");
    else -> println("qualquer numero");
}
```

<hr>

## Usando when sem parametro
Quando temos várias condicoes diferentes, podemos deixar a condicao em cada 'case':

```kotlin
val nomeDoCliente: String = "naruto";
val tipoDaConta: String = "avançada";

when{
    tipoDaConta == "basica" -> println("conta fraca");
    tipoDaConta == "intermediaria" -> println("conta mais ou menos");
    tipoDaConta == "avançada" && nomeDoCliente == "naruto" -> println("conta pica");
    else -> println("nao existe");
}
```

## when como expressão (retornando algum valor)

Nós conseguimos atribuir valor a uma variável dependendo de uma condição. Para isso, em outras linguagens usamos o operador ternário. No Kotlin não existe esse operador — usamos o `when` como expressão no lugar.

Expressao -> Retorna algum valor.

`when` como expressao -> when vai retornar algum valor

```kotlin
val numeroInsano: Int = 235;

val numeroEhGrandao: String = when(numeroInsano){
    in 1..10 -> "numero PERFEITO"
    55 -> "55 eh tao legal"
    77 -> "55 eh tao legal"
    in 100..300 -> "numero GRANDE"
    else -> "outros numeros"
}
```
