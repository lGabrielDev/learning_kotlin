## Variables

Lugar para armazenar um valor.

📖 Padrao **camelCaseIgualzinhoAoJava**

<hr>
<br>

### `var` and `val`

- **var** -> podemos atribuir outro valor pra ela
- **val** -> nao podemos atribuir valor. É uma final variable by Java.

```kt
var texto1: String = "Primeiro";
texto1 = "Segundo";

//final variable
val texto2: String = "Nao dá pra alterar";
texto2 = "a"; //ERRO!
```
<hr>
<br>

### `const val`

Constante que geralmente declaramos lá em cima no escopo da Class.

Comparando com Java, seria uma `public static final`.


```kt
//public static final
//constantes que nao podem receber valor de uma funcao.
//Porque elas são lidas em tempo de 'compilacao'. Os valores das funcoes nao sao lidos nesse momento.
const val caminhoApi: String = "http://localhost:blablalba";
const val senhaTal: Int = 33;
const val constanteDeCompilacao3: Boolean = true;


fun main(args: Array<String>) {
    println(constanteDeCompilacao1);
    println(constanteDeCompilacao2);
    println(constanteDeCompilacao3);
}
```

### Comparando com java

<br>

Java
```java
Integer n1 = 22222;
final Integer n2 = 22222;
public static final int N3 = 22222;
```

<br>

Kotlin
```kt
var n1: Int = 22; //podemos atribuir outros valores
val n2: Int = 22; //final variable
const val n3: Int = 22; //public static final
```
