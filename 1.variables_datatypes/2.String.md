## String Templates (formatando String)


## Principais methods da class String

| Método/Property | O que faz |
|---|---|
| `.length` | Tamanho da string (property) |
| `.uppercase()` | Tudo maiúsculo |
| `.lowercase()` | Tudo minúsculo |
| `.trim()` | Remove espaços nas bordas |
| `.contains()` | Verifica se contém algo |
| `.startsWith()` | Começa com? |
| `.endsWith()` | Termina com? |
| `.replace()` | Substitui trecho |
| `.isEmpty()` | Está vazio? |
| `.isBlank()` | Vazio ou só espaços? |
| `.substring()` | Pega um pedaço |
| `.split()` | Separa por delimitador |
