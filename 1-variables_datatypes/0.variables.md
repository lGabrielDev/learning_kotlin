<hr>

### `var` and `val`

- **var** -> podemos atribuir outro valor pra ela
- **val** -> nao podemos atribuir valor. É uma final variable by Java.

```kt
var texto1: String = "Primeiro";
texto1 = "Segundo";

//final variable
val texto2: String = "Nao dá pra alterar";
texto2 = "a"; //ERRO!
```
