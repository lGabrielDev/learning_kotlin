# Constantes

Constante é um valor definido em tempo de compilação que não pode ser alterado durante a execução do programa.

---

## Comparando com Java

No Java, normalmente criamos constantes usando:

`public static final`

No Kotlin, usamos:

`const val`

---

## Convenção de nomenclatura

Por convenção, constantes são escritas com **letras maiúsculas**, usando `_` para separar as palavras.

```kotlin
//arquivo kotlin sem nenhuma Class
const val CONFIG_1 = "url_tal";
const val CONFIG_2 = 123;
```

---

## Onde podemos usar constantes?

Geralmente usamos constantes em 3 cenários:

1. Em um arquivo específico somente para constantes

1. Em um arquivo de uma Class, lá no topo

1. Dentro de um singleton object

1. Dentro de um companion object

<br>

### 1. Em um arquivo específico somente para constantes

```kotlin
//no topo, fora da Class
const val CONFIG_1 = "url_tal";
const val CONFIG_2 = 123;
```

```kotlin
fun main(args: Array<String>){
    CONFIG_1;
    CONFIG_2;
}
```

:book: Como essas constantes ficam "soltas" / FORA de uma class, nós chamamos elas diretamente.

<br>

### 2. Em um arquivo de uma Class

```kotlin
const val CONFIG_1 = "url_tal";
const val CONFIG_2 = 123;

class Teste () {

}
```

> :warning: Uma classe normal não pode ter um `const val` diretamente em seu corpo. Para ter uma constante associada à classe, utilizamos um `companion object`.
>
> Perceba que colocamos lá em cima do arquivo, FORA da class.

```kotlin
fun main(args: Array<String>){
    CONFIG_1;
    CONFIG_2;
}
```

:book: Como essas constantes ficam "soltas" / FORA de uma class, nós chamamos elas diretamente.

<br>

### 3. Dentro de um `singleton object` 

Constantes de uma class específica, que só existe 1 instancia

```kotlin
object ConfiguracaoBolada {
    const val CONFIG_1 = "url_tal";
    const val CONFIG_2 = 123;
}
```

```kotlin
fun main(args: Array<String>){
    ConfiguracaoBolada.CONFIG_1
}
```

<br>

### 4. Dentro de um `companion object`

Constantes de uma class específica

```kotlin
class Person () {

    companion object {
        const val CONFIG_1 = "url_tal";
        const val CONFIG_2 = 123;
    }
    
}
```

```kotlin
fun main(args: Array<String>){
    Person.CONFIG_1
    Person.CONFIG_2
}
```
