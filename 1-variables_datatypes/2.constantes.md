# Constantes

Constante é um valor definido em tempo de compilação que não pode ser alterado durante a execução do programa.

---

## Comparando com Java

No Java, normalmente criamos constantes usando:

`public static final`

No Kotlin, usamos:

`const val`

---

## Convenção de nomenclatura

Por convenção, constantes são escritas com **letras maiúsculas**, usando `_` para separar as palavras.

```kotlin
const val CAMINHO_API = "caminho_tal"
const val TIMEOUT = 30
const val NOME_EMPRESA = "Itaú"
```

---

## Onde podemos usar constantes?

Geralmente usamos constantes em 3 cenários:

1. No topo do arquivo (fora de uma Class, ou um arquivo exclusivo de constantes)

2. Dentro de um singleton object

3. Dentro de um companion object

<br>

### 1. No topo do arquivo, fora da Classe

Podemos criar constantes no topo do arquivo, fora de qualquer classe. Também é comum criar um arquivo exclusivo para as constantes.

```kotlin
//arquivo de uma Class
const val CAMINHO_API = "caminho_tal";
const val TIMEOUT = "caminho_tal";
const val AMBIENTE = "prod";

class Teste () {

}
```

```kotlin
//no topo, fora da Class
const val CAMINHO_API = "caminho_tal";
const val TIMEOUT = "caminho_tal";
const val AMBIENTE = "prod";
```

<br>

### 2. Dentro de um `singleton object` 

Constantes de uma class específica, que só existe 1 instancia

```kotlin
object ConfiguracaoBolada {
    const val CONFIG_1 = "asdsa";
}


fun main(args: Array<String>){
    ConfiguracaoBolada.CONFIG_1
}

```

<br>

### 3. Dentro de um `companion object`

Constantes de uma class específica

```kotlin
class Person () {

    companion object {
        const val CONFIG_1 = "asdsa";
        const val CONFIG_2 = 123;
    }

}


fun main(args: Array<String>){
    Person.CONFIG_1;
    Person.CONFIG_2;
}
```
