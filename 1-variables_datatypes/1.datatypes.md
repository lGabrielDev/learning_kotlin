# Datatypes

Padrao Java.

```kt
fun main(args: Array<String>) {

    // === numeros inteiros ===
    var l: Long = 1L;
    var i: Int = 1;
    var s: Short = 1;
    var b: Byte = 1;

    // === numero decimal ===
    var f: Float = 2.2f;
    var d: Double = 2.2; //Mais preciso. Tem mais casas decimais.

    // === String ===:
    var textoInsano: String = "Salve";

    // === Char ===:
    var charInsano: Char = 'A';

    // === Boolean ===:
    var trueOrFalse: Boolean = true;
}
```

📖 Os datatypes são os mesmos do Java. A diferença é que no Kotlin é `Int`.

<br>

💡 Igualzinho no Java, se você criar uma variable de número inteiro, o Kotlin declara essa variable como `Int`.

💡 Igualzinho no Java, se você criar uma variable de número decimal/quebrado, o Kotlin declara essa variable como `Double`.

<hr>
<br>

## Curiosidade do Double aqui no kotlin
O `double` no Kotlin não aceita número `Int`. Ele precisa ser de fato 'quebrado'.

```kotlin
val n1: Double = 2; //errado
val n1: Double = 2.0; //certo
```

## Type Inference

Você não é obrigado a informar o datatype do objeto / variable.

O compilador do Kotlin é inteligente o suficiente pra olhar pro valor da variable e saber seu datatype.

```kt
var n1 : Int = 22;
var n2 = 22;

var numeroQuebrado1 = 44f;
var numeroQuebrado2: Float = 44f;

var texto1: String = "Salve";
var texto2 = "Salve";

var true1: Boolean = false;
var true2 = false;
```

<hr>
<br>

## Não usamos primitive datatype no Kotlin

Em Kotlin tudo é um objeto. Não existem tipos primitivos como no Java — aqui usamos sempre as wrapper classes (`Int`, `Double`, `Boolean`, etc).


Relembrando:
- **Tipos primitivos** → `int`, `double`, `boolean` (Java)
- **Wrapper classes** → tipos primitivos transformados em objetos (`Integer`, `Double`, `Boolean`)
