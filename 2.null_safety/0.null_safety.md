# Null Safety '?'

No kotlin, nós não podemos atribuir um valor `null` para uma variable. Assim, evitamos o erro de `NullPointerException`.

Esse erro de `NullPointerException` acontece quando tentamos usar algum method/function em uma variable que tem valor null.

Concorda comigo que não é possível usar um `uppercase()` em null? Isso daria um erro! Não tem como deixar em letras maiúsculas algo que é null/nada.



<br>

A ideia do Null Safety é pra identificar o possível erro de NullPointer no momento de compilacao/escrita do seu código. E não depois, quando você executa seu código. Identificamos o erro antes.

<hr>
<br>

## Habilitando uma variable para receber null

Como vimos antes, uma variable não pode receber null. Para liberar, vamos usar o `?`.

```kt
var texto: String = "olá";
texto = null; //ERRO!

var texto2: String? = "olá";
texto2 = null; //liberado
```

<br>

## Safe call, chamando methods em uma variable de forma safe `?.`

Para nao dar erro de compilacao nós precisamos fazer um if else pra conseguir usar o method. Nesse caso o method que vamos usar é o `upperCase()`

```kt
val texto1: String? = null;

if(texto1 != null){
   println(texto1.uppercase())
}
```

<br>

Para nao escrever tudo isso, podemos fazer usando o `?.`

```kt
val texto1: String? = null;
println(texto1?.uppercase())
//null

val texto2: String? = null;
println(texto2?.uppercase() ?: "Valor é null")
// valor é null
```

<hr>
<br>

## Elvis operator `?:`

Caso a operacao da esquerda seja null, setamos um valor.

Se for null, use esse valor aqui.

```kt
val texto1: String? = "Valor qualquer";
val texto2: String = texto1 ?: "eh nulo";
```

<hr>
<br>


## Resumindo `?`

1. Quer liberar uma variable para receber valor null? `?`

   ```kt
   var texto: String? = null;
   ```

<br>

2. Quer usar methods em uma variable que pode ter valor null? `?.methodTal()`

   ```kt
   println(texto?.uppercase());
   //Se tiver realmente um valor, execute o method upperCase();
   //Caso contrário, retorna null
   ```

<br>

2. Quer especificar o retorno, caso o valor seja null? `?: Elvis operator`

   ```kt
   println(texto2?.uppercase() ?: "Valor é null")
   ```
